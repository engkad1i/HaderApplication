# 📱 Hader - Smart Attendance Management System

## 📌 Project Overview

**Hader** is an intelligent, cross-platform attendance management solution designed to modernize and automate attendance tracking. Built with **Flutter** and backed by **Firebase**, the application addresses traditional proxy attendance and tracking inefficiencies by combining **dynamic QR code generation** with **precise geolocation (GPS) verification**.

The system ensures that attendance is logged securely, accurately, and only when the user is physically present within designated parameters.

## ✨ Key Features

*  **Dynamic QR Code Scanning:** Time-sensitive, auto-refreshing QR codes to prevent unauthorized sharing and fraud.
*  **Geolocation Validation:** Integrated GPS fencing to verify physical presence within specified boundaries before accepting logs.
*  **Real-Time Data Sync:** Instant synchronization of attendance records, logs, and user states powered by Firebase Cloud Firestore.
* **Comprehensive Analytics & Reporting:** Interactive dashboards providing detailed history, attendance summaries, and status tracking for users and administrators.
*  **Instant Push Notifications:** Automated alerts for upcoming sessions, successful check-ins, and system updates.
*  **Secure Authentication:** Role-based access control and user authentication using Firebase Auth.
